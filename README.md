🛒 TaloShop – Website Bán Quần Áo
TaloShop là một website thương mại điện tử chuyên bán quần áo, được xây dựng với đầy đủ chức năng cho người dùng và trang Admin quản lý. Dự án tập trung vào trải nghiệm mua sắm trực tuyến mượt mà, xử lý dữ liệu động và quản lý hệ thống hiệu quả.

👤 Chức năng người dùng:
- Xem danh sách và chi tiết sản phẩm quần áo.
- Tìm kiếm, lọc sản phẩm theo danh mục.
- Thêm sản phẩm vào giỏ hàng.
- Liên hệ để được giúp đỡ
- Đặt hàng và gửi thông tin mua hàng trực tuyến.

🛠️ Chức năng Admin:
- Quản lý sản phẩm (thêm / sửa / xóa).
- Quản lý danh mục.
- Quản lý đơn hàng và trạng thái xử lý.
- Quản lý dữ liệu người dùng.

⚙️ Công nghệ sử dụng:
- Frontend: HTML, CSS, JavaScript, jQuery, AJAX.
- Backend: C# (ASP.NET).
- Database: SQL Server.

✨ Điểm nổi bật:
-Giao diện trực quan, dễ sử dụng.
- Trang Admin riêng biệt, phân quyền rõ ràng.
- Dữ liệu được xử lý động bằng AJAX, hạn chế reload trang.
